## [LEGO-Anything 用编码智能体将单张图像重建为可编辑的 Blender 场景程序](https://huggingface.co/papers/2609.36380) ⭐️ 8.0/10

LEGO-Anything 是一个 Image-to-Code 框架，其中编码智能体会迭代地编写、执行并修改 Blender 代码，从而从单张图像重建三维场景；作者同时提出了 LEGO-Bench，这是一个基于模拟器的基准，包含来自 104 个室内外场景的 208 张图像，并分别对产物有效性、可见表面几何和渲染外观进行评分。在受评估的智能体中，GPT-6-astra 表现最佳，室内得分 53.4%、室外得分 39.6%，而无需训练的 LEGO-Plugin 框架使全部六个被测模型的总体得分相对提升最高达 62.7%。 将重建场景表示为可执行程序而非固定的网格或渲染结果，使其可被检查、编辑和查询，这可能改变视觉系统与三维内容流水线之间的协作方式。结果同时表明当前编码智能体存在明显上限，因为程序构建的场景在检测、分割和深度任务上仍落后于专用视觉模型。 LEGO-Bench 基于模拟器构建，即真值场景由模拟器生成，因此评估可以自动进行且易于扩展，并且它从三个独立维度评分，而非只给出单一相似度数值。作者指出智能体轨迹中反复出现的三类问题——场景初始化薄弱、迭代过程中出现退化性编辑、以及自我评估不可靠；在 LEGO-World 中，他们将对 GPT-6-astra 重建场景的物体检测、实例掩码和相对深度作为确定性查询导出，发现性能虽非平凡但仍不及专用模型。

huggingface_papers · Hugging Face Papers · 9月30日 00:00

**背景**: Blender 是一款免费开源的 3D 创作套件，用于建模、动画、渲染和视觉特效，其 Python 脚本接口允许程序以过程化方式构建场景。单图像三维重建传统上产生点云、网格或神经 SDF 等神经表示，这些结果难以编辑或查询。编码智能体是基于大语言模型的系统，能够在循环中编写并运行代码，本文将该范式应用于场景重建，让智能体检查渲染结果并修改其 Blender 程序。

## [Marathoner 实现超长时程自主智能体](https://huggingface.co/papers/2609.34378) ⭐️ 8.0/10

一篇名为 Marathoner 的新预印本论文提出了一套完整的后训练流程，通过从包含 1000 多行新代码的 GitHub 发布 PR 中合成高难度任务，并将多个任务链接在一起，从而将超长时程执行能力注入基础模型。该方法结合了拒绝采样微调与真实沙箱中的强化学习，并提出了一种新颖的“后期阶段奖励”（Later Stage Bonus Reward），鼓励模型在执行后期进行有意义的操作。 当前 AI 智能体在长时间持续、目标导向的行为方面表现不佳，而 Marathoner 通过使模型能够在极具挑战性的任务上连续工作 10 小时以上并执行 1000 多次工具调用，解决了这一局限。这可能会显著推动软件工程及其他需要长期规划的领域中的自主智能体发展，甚至有望超越强大的专有模型。 该流程从包含 1000 多行新代码的重大发布 PR 中合成任务级数据，利用多任务链接创建前沿难度的任务，并将拒绝采样微调与强化学习相结合，其中冷启动模型在独立沙箱中执行真实世界操作。在 5 个基准测试上的评估显示，该方法相比基础模型有持续改进，甚至超越了强大的专有模型。

huggingface_papers · Hugging Face Papers · 9月30日 00:00

**背景**: AI 智能体中的长时程规划指的是在大时间尺度上合成并执行一系列扩展的决策和工具调用，以完成复杂目标的能力。后训练流程，如拒绝采样微调和强化学习，用于使基础模型适应特定能力。GitHub 拉取请求可作为真实世界编码任务的来源，而多任务链接则将较简单的任务组合成更困难的任务，以突破模型极限。

## [PS5 Relapse 漏洞利用可越狱 7.00 至 13.60 固件](https://github.com/ntfargo/Relapse-Exploit) ⭐️ 8.0/10

开发者 ntfargo 在 GitHub 上发布了名为 Relapse Exploit 的新 PS5 漏洞利用链，可对运行 7.00 至 13.60 固件的 PlayStation 5 主机实现越狱。它通过本地 Python 服务器（serve.py）或 GitHub Pages 页面在 PS5 浏览器中打开来使用。 针对大量较新 PS5 固件的可用越狱是一项重要的技术成就，可能为主机带来自制软件、存档备份及其他非官方软件，同时也会促使索尼修补底层漏洞。它影响使用 7.00 至 13.60 固件的 PS5 用户以及整个主机安全社区。 据报道，该漏洞利用链结合了 WebKit 漏洞与内核竞争条件，且 9 月 16 日之后更新的主机不兼容，因此并非所有 PS5 用户都能使用。仓库地址为 github.com/ntfargo/Relapse-Exploit，可在本地运行或通过项目的 GitHub Pages 站点使用。

## [隐私分析揭示对话式 AI 代理的追踪风险](https://jorgegarciaherrero.com/wp-content/interactivos/20260916-Prompt-like-a-butterfly-sting-like-a-tracker-(clean).pdf) ⭐️ 8.0/10

一篇题为《像蝴蝶一样提示，像追踪器一样蜇人》的新论文对网页端和移动端对话式 AI 代理进行了隐私分析，记录了追踪机制和数据泄露风险。该研究在 Hacker News 上获得 412 分和 130 条评论，重点指出了部分提示传输和基于 UUID 的不安全对话 URL 等问题。 随着对话式 AI 代理深度融入日常工作流程，其带来的隐私风险影响着数亿用户，而这些人可能误以为自己的交互是保密的。这些发现凸显了 AI 公司渴求数据的商业模式与用户隐私期望之间的更广泛矛盾，可能进一步推动对开放权重和自托管替代方案的需求。 该分析覆盖网页端和移动端代理，考察追踪器和广告机制如何捕获提示数据，并指出基于 UUID 的 URL 常被错误地当作隐私保护措施。社区报告补充了具体案例：ChatGPT 会定期将未完成的提示发送到`conversation/prepare`端点，而 Perplexity 的搜索 URL 会向任何持有链接的人暴露完整的过往对话。

hackernews · damaru2 · 9月29日 09:03 · [社区讨论](https://news.ycombinator.com/item?id=49890226)

**背景**: 对话式 AI 代理是指 ChatGPT、Perplexity 等允许用户通过自然对话与大语言模型交互的服务。隐私研究者关注这些系统如何处理用户数据，包括提示是否在发送前就被传输、对话如何存储，以及界面中是否嵌入了广告追踪器。UUID（通用唯一标识符）是常用于 URL 中引用资源的随机字符串，但它并非访问控制手段——任何获得链接的人通常都能查看内容。
